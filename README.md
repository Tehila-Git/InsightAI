# InsightAI

AI-powered data analysis platform.

InsightAI is a local-first data intelligence platform that helps users explore, analyze, and understand their datasets through automated analysis, interactive visualizations, and natural-language questions.

## Key Features

- Upload and analyze CSV and Excel files
- Automated data profiling and statistical summaries
- Interactive data visualizations
- Correlation and anomaly detection
- Natural-language questions about datasets
- Local-first processing and storage

## Technology Stack

- **Frontend:** React, TypeScript
- **Backend:** Python, FastAPI
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** scikit-learn
- **Local LLM:** Ollama
- **Database:** SQLite
- **Testing:** Pytest, Vitest

## Project Status

Under active development.

## Development Approach

InsightAI is being developed with an emphasis on:

- Modular architecture
- Automated testing
- Code quality
- Data security
- Reproducible development workflows
